ಮುಂದೆ - ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ Claude Code ಅನ್ನು ಇನ್ಸ್ಟಾಲ್ ಮಾಡೋಣ. ನಾವು Claude Code ಡೆಸ್ಕ್‌ಟಾಪ್ ಅಪ್ಲಿಕೇಶನ್ ಬಳಸಲಿದ್ದೇವೆ, ಇದರಲ್ಲಿ ನಿರ್ಮಾಣ ಪ್ರಾರಂಭಿಸಲು ಬೇಕಾದ ಎಲ್ಲವೂ ಸೇರಿದೆ.

## Claude Code ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ

### Windows/Mac

1. **[claude.ai/download](https://claude.ai/download)** ಗೆ ಹೋಗಿ (ಅಥವಾ ಅಧಿಕೃತ Claude Code ಡೌನ್‌ಲೋಡ್ ಪುಟ)
2. **"Download for Windows/Mac"** ಕ್ಲಿಕ್ ಮಾಡಿ
3. ಇನ್‌ಸ್ಟಾಲರ್ ಡೌನ್‌ಲೋಡ್ ಆಗುತ್ತದೆ (ಸಾಮಾನ್ಯವಾಗಿ ನಿಮ್ಮ Downloads ಫೋಲ್ಡರ್‌ಗೆ)

## Claude Code ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ

### Windows

1. ನಿಮ್ಮ Downloads ಫೋಲ್ಡರ್‌ನಿಂದ ಡೌನ್‌ಲೋಡ್ ಆದ ಫೈಲ್ ತೆರೆಯಿರಿ
2. ಇನ್‌ಸ್ಟಾಲೇಶನ್ ವಿಝಾರ್ಡ್ ಅನುಸರಿಸಿ
3. **"Install"** ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಇನ್‌ಸ್ಟಾಲೇಶನ್ ಪೂರ್ಣಗೊಳ್ಳುವವರೆಗೆ ಕಾಯಿರಿ
4. ಮುಗಿದ ನಂತರ **"Finish"** ಕ್ಲಿಕ್ ಮಾಡಿ

### Mac

1. ನಿಮ್ಮ Downloads ಫೋಲ್ಡರ್‌ನಿಂದ ಡೌನ್‌ಲೋಡ್ ಆದ `.dmg` ಫೈಲ್ ತೆರೆಯಿರಿ
2. **Claude Code** ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನಿಮ್ಮ **Applications** ಫೋಲ್ಡರ್‌ಗೆ ಎಳೆಯಿರಿ
3. **Applications** ತೆರೆದು **Claude Code** ಅನ್ನು ಡಬಲ್-ಕ್ಲಿಕ್ ಮಾಡಿ
4. ಭದ್ರತಾ ಎಚ್ಚರಿಕೆ ಕಂಡುಬಂದರೆ, ದೃಢೀಕರಿಸಲು **"Open"** ಕ್ಲಿಕ್ ಮಾಡಿ

### Github ಅನ್ನು Claude Code ಗೆ ಸಂಪರ್ಕಿಸಿ
![](../../install-claude-code/github-claude-settings.png)

ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು, Claude Code ಅನ್ನು Github ಗೆ ಸಂಪರ್ಕಿಸಬೇಕು. Claude ನ ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಗೆ ಹೋಗಿ Github ಅನ್ನು ಸಂಪರ್ಕಿಸಿ.

ನಿಮ್ಮ Github ಲಾಗಿನ್ ದೃಢೀಕರಿಸಬೇಕಾಗುತ್ತದೆ, ಮತ್ತು ನಂತರ ನಿಮ್ಮನ್ನು **Integrations > Applications > Claude** ಪುಟಕ್ಕೆ ಕರೆದೊಯ್ಯಲಾಗುತ್ತದೆ. ಇಲ್ಲಿ ನೀವು ಎಲ್ಲಾ ರೆಪೊಸಿಟರಿಗಳ ಪ್ರವೇಶ ಅಥವಾ ನೀವು ಈಗ ಕೆಲಸ ಮಾಡುತ್ತಿರುವ ಒಂದನ್ನು ಮಾತ್ರ ಆಯ್ಕೆ ಮಾಡುವ ಆಯ್ಕೆ ಮಾಡಬಹುದು.

'**Select repository**' ಆಯ್ಕೆ ಮಾಡಿದರೆ, ನೀವು ತಾಜಾ ರಚಿಸಿದ ರೆಪೊಸಿಟರಿ ಆಯ್ಕೆ ಮಾಡಬಹುದು.

![](../../install-claude-code/repo-claude.png)

### ಇನ್‌ಸ್ಟಾಲೇಶನ್ ನಂತರ Claude Code ಕಾಣಿಸುತ್ತಿಲ್ಲ (Mac)
ನಿಮ್ಮ **Applications** ಫೋಲ್ಡರ್ ಪರಿಶೀಲಿಸಿ. Claude Code ಅಲ್ಲಿದ್ದರೂ ತೆರೆಯದಿದ್ದರೆ, ಅದರ ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಭದ್ರತಾ ಎಚ್ಚರಿಕೆ ಬೈಪಾಸ್ ಮಾಡಲು **"Open"** ಆಯ್ಕೆ ಮಾಡಿ.

### ಇನ್‌ಸ್ಟಾಲೇಶನ್ ನಿಂತಿದೆ ಅಥವಾ ಪೂರ್ಣಗೊಳ್ಳುತ್ತಿಲ್ಲ (Windows)

ಇನ್‌ಸ್ಟಾಲರ್ ಅನ್ನು Administrator ಆಗಿ ಚಲಾಯಿಸಲು ಪ್ರಯತ್ನಿಸಿ:
1. ಇನ್‌ಸ್ಟಾಲರ್ ಫೈಲ್ ಮೇಲೆ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ
2. **"Run as administrator"** ಆಯ್ಕೆ ಮಾಡಿ
3. ಮತ್ತೆ ಇನ್‌ಸ್ಟಾಲೇಶನ್ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಿ

### "App is damaged" ಸಂದೇಶ (Mac)

ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ಅಪ್ಲಿಕೇಶನ್‌ಗಳಲ್ಲಿ ಇದು ಸಂಭವಿಸಬಹುದು. ಪ್ರಯತ್ನಿಸಿ:
1. **Terminal** ತೆರೆಯಿರಿ
2. ಚಲಾಯಿಸಿ: `xattr -cr /Applications/Claude\ Code.app`
3. ಮತ್ತೆ Claude Code ತೆರೆಯಲು ಪ್ರಯತ್ನಿಸಿ

### "npm is not recognized" (Windows)

Command Prompt ಸಂಪೂರ್ಣವಾಗಿ ಮುಚ್ಚಿ ಮತ್ತೆ ತೆರೆಯಿರಿ. ಇನ್‌ಸ್ಟಾಲೇಶನ್‌ಗೆ ಹೊಸ ವಿಂಡೋ ಅಗತ್ಯವಿದೆ.


## ಮುಂದಿನ ಹಂತಗಳು

Claude Code ಇನ್‌ಸ್ಟಾಲ್ ಆಗಿದೆ ಮತ್ತು Github ಸೆಟಪ್ ಆಗಿದೆ, ಹಾಗಾಗಿ ನೀವು ಈಗ ಹೊರಡಲು ಸಿದ್ಧರಾಗಿದ್ದೀರಿ! ಮುಂದೆ, ನೀವು Claude Code ನೊಂದಿಗೆ ನಿರ್ಮಿಸಲು ಒಂದು ಯೋಜನೆ ಆಯ್ಕೆ ಮಾಡುವಿರಿ.
