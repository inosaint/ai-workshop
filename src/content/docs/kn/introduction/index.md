ನೀವು ಒಂದು ರೋಮಾಂಚಕ ಪ್ರಯಾಣವನ್ನು ಪ್ರಾರಂಭಿಸಲು ಹೊರಟಿದ್ದೀರಿ. ಈ ವರ್ಕ್‌ಶಾಪ್‌ನ ಅಂತ್ಯದ ವೇಳೆಗೆ, ನೀವು ಕಲಿಯುವಿರಿ:

- AI ಪರಿಸರ ವ್ಯವಸ್ಥೆಯೊಂದಿಗೆ ಪರಿಚಿತರಾಗಿ
- AI ನಿಮಗೆ ಹೇಗೆ ಸಹಾಯ ಮಾಡಬಹುದು ಎಂಬುದನ್ನು ಅನುಭವಿಸಿ
- ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿ ನೇರವಾಗಿ ಚಾಲನೆಯಾಗುವ ನಿಜವಾದ ಪ್ರಾಜೆಕ್ಟ್. ಉಚಿತವಾಗಿ.

ಮತ್ತು ಉತ್ತಮ ಭಾಗ? **ನಿಮಗೆ ಯಾವುದೇ ಪೂರ್ವ ಕೋಡಿಂಗ್ ಅನುಭವದ ಅಗತ್ಯವಿಲ್ಲ.**


## ಈ ಮಾರ್ಗದರ್ಶಿ ಯಾರಿಗಾಗಿ?

ಹಿಂದಿನ ಸಾಲಿನಲ್ಲಿ ಹೇಳಿದಂತೆ, ಈ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಆರಂಭಿಕರಾಗಿರುವ ಮತ್ತು ಯಾವುದೇ ಪೂರ್ವ ಕೋಡಿಂಗ್ ಅನುಭವವಿಲ್ಲದ ಯಾರಿಗಾದರೂ ಬರೆಯಲಾಗಿದೆ.

ನಾನು [ನವೆಂಬರ್ 2025 ರಲ್ಲಿ vibe coding ಪ್ರಾರಂಭಿಸಿದಾಗ](http://kenneth.dsouza.im/writing/vibe-coding/) ಮತ್ತು ನನ್ನ ಸ್ನೇಹಿತರೊಂದಿಗೆ ನನ್ನ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳನ್ನು ಹಂಚಿಕೊಂಡಾಗ, ಅನೇಕರು vibecoding ಪ್ರಯತ್ನಿಸಲು ಆಸಕ್ತಿ ವ್ಯಕ್ತಪಡಿಸಿದರು, ಆದರೆ ಜನರಿಗೆ ಸ್ವಂತವಾಗಿ ನಿರ್ಮಿಸಲು ಸಹಾಯ ಮಾಡುವ ಯಾವುದೇ ಸಂಪನ್ಮೂಲ ಇರಲಿಲ್ಲ ಎಂದು ನನಗೆ ಕಂಡುಬಂತು. ಹೆಚ್ಚಿನ ಸಂಪನ್ಮೂಲಗಳು, ಅಧಿಕೃತ ಸಂಪನ್ಮೂಲಗಳೂ ಸಹ, ಮಧ್ಯಂತರ ಅಥವಾ ತಜ್ಞ ಬಳಕೆದಾರರಿಗಾಗಿ ಬರೆಯಲ್ಪಟ್ಟಿರುತ್ತವೆ.

ಹೌದು, Replit ಮತ್ತು Figma Make ನಂತಹ AI ಆಧಾರಿತ vibe-coding ವ್ಯವಸ್ಥೆಗಳಿವೆ, ಆದರೆ ಅವು ನಿಮ್ಮನ್ನು ತಮ್ಮ ಖಾಸಗಿ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳಲ್ಲಿ ಲಾಕ್ ಮಾಡಿಬಿಡುತ್ತವೆ. ಆದ್ದರಿಂದ ನಾನು vibe coding ಕಡೆಗೆ ನನ್ನ ವಿಧಾನದ ಆಧಾರದ ಮೇಲೆ ಒಂದು ಸರಳ ಮಾರ್ಗದರ್ಶಿ ಬರೆಯಲು ನಿರ್ಧರಿಸಿದೆ (ಒಂದು ಕಾಣೆಯಾದ ಕೈಪಿಡಿ ಎನ್ನಬಹುದೇ?), ಇದು ಹೊಸ ಬಳಕೆದಾರರಿಗೆ vibe coding ಅನ್ನು ಅನುಭವಿಸಲು ಮತ್ತು ನಿರ್ಮಿಸಲು ಪ್ರಾರಂಭಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ ಎಂದು ಆಶಿಸುತ್ತೇನೆ.

## ಮುಂದಿನ ಪ್ರಯಾಣ

ಇಲ್ಲಿ ನಮ್ಮ ರೋಡ್‌ಮ್ಯಾಪ್ ಇದೆ:

```
[ನೀವು ಇಲ್ಲಿದ್ದೀರಿ]
      ↓
┌─────────────────────┐
│  0. QUICK WIN       │ ← 60 ಸೆಕೆಂಡ್‌ಗಳಲ್ಲಿ AI ಮಾಯಾಜಾಲವನ್ನು ಅನುಭವಿಸಿ
├─────────────────────┤
│  1. SETUP           │ ← ಖಾತೆಗಳನ್ನು ರಚಿಸಿ, ಉಪಕರಣಗಳನ್ನು ಸ್ಥಾಪಿಸಿ
├─────────────────────┤
│  2. LEARN GIT       │ ← ಕೋಡ್ ಅನ್ನು ಹೇಗೆ ಉಳಿಸಲಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ
├─────────────────────┤
│  3. BUILD           │ ← Claude ನೊಂದಿಗೆ ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ರಚಿಸಿ
├─────────────────────┤
│  4. TEST            │ ← ಎಲ್ಲವೂ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿ
├─────────────────────┤

      ↓
```

## ನಿಮಗೆ ಏನು ಬೇಕಾಗುತ್ತದೆ

ನಾವು ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು, ನಿಮ್ಮ ಬಳಿ ಇವೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ:

- ✅ ಒಂದು ಕಂಪ್ಯೂಟರ್ (Windows ಅಥವಾ Mac)
- ✅ ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕ
- ✅ ಸುಮಾರು 3 ಗಂಟೆಗಳ ಕೇಂದ್ರೀಕೃತ ಸಮಯ
- ✅ ಕುತೂಹಲ ಮತ್ತು ತಾಳ್ಮೆ!

ಅಷ್ಟೇ. ಯಾವುದೇ ವಿಶೇಷ ಸಾಫ್ಟ್‌ವೇರ್, ಕೋಡಿಂಗ್ ಜ್ಞಾನ, ಅಥವಾ ಅನುಭವದ ಅಗತ್ಯವಿಲ್ಲ.


## ತಪ್ಪುಗಳನ್ನು ಮಾಡುವ ಬಗ್ಗೆ ಒಂದು ಟಿಪ್ಪಣಿ

ಇಲ್ಲಿ ಅನುಭವಿ ಡೆವಲಪರ್‌ಗಳಿಗೆ ತಿಳಿದಿರುವ ಒಂದು ರಹಸ್ಯವಿದೆ:

> **ಪ್ರತಿಯೊಬ್ಬರೂ ತಪ್ಪುಗಳನ್ನು ಮಾಡುತ್ತಾರೆ.**

ಏನಾದರೂ ತಪ್ಪಾದಾಗ (ಮತ್ತು ಅದು ಆಗುತ್ತದೆ), ಅದು ವಿಫಲತೆಯಲ್ಲ — ಅದು ಕಲಿಕೆ. ಪ್ರತಿ ದೋಷ ಸಂದೇಶವು ಒಂದು ಸುಳಿವು. ಪ್ರತಿ ಬಗ್ ಒಂದು ಪರಿಹರಿಸಬೇಕಾದ ಒಗಟು.

ಈ ವರ್ಕ್‌ಶಾಪ್‌ನಲ್ಲಿ ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳಿಗಾಗಿ [Troubleshooting](/troubleshooting/) ವಿಭಾಗವಿದೆ.
