## ವಿಧಾನ 2: ಫೈಲ್‌ಗಳನ್ನು ನೀವೇ ಸಂಪಾದಿಸಿ

ನೀವು ಯಾವುದೇ ಟೆಕ್ಸ್ಟ್ ಎಡಿಟರ್ ಬಳಸಿ ನೇರವಾಗಿ ಫೈಲ್‌ಗಳನ್ನು ಸಂಪಾದಿಸಬಹುದು:

1. ಟೆಕ್ಸ್ಟ್ ಎಡಿಟರ್‌ನಲ್ಲಿ ಫೈಲ್ ತೆರೆಯಿರಿ (VS Code, Notepad++, TextEdit, ಇತ್ಯಾದಿ)
2. ನಿಮ್ಮ ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಿ
3. ಫೈಲ್ ಉಳಿಸಿ
4. ಬದಲಾವಣೆಗಳನ್ನು ನೋಡಲು ನಿಮ್ಮ ಬ್ರೌಸರ್ ರಿಫ್ರೆಶ್ ಮಾಡಿ

### GitHub Desktop ನೊಂದಿಗೆ ನಿಮ್ಮ ಪ್ರಗತಿಯನ್ನು ಉಳಿಸಿ

ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್‌ಗೆ ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಿದ ನಂತರ, GitHub Desktop ನೊಂದಿಗೆ ಅವುಗಳನ್ನು ಉಳಿಸೋಣ:

#### ಹಂತ 1: GitHub Desktop ತೆರೆಯಿರಿ

1. GitHub Desktop ಗೆ ಬದಲಾಯಿಸಿ.
2. Claude Code ಮಾಡಿದ ಬದಲಾವಣೆಗಳನ್ನು ತರಲು ಮತ್ತು ಸ್ಥಳೀಯವಾಗಿ ಪರಿಶೀಲಿಸಲು '**Fetch Origin**' ಕ್ಲಿಕ್ ಮಾಡಿ.
3. ನೀವು ಎಡಿಟರ್‌ನಲ್ಲಿ ಕೈಯಾರೆ ಯಾವುದೇ ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಿದ್ದರೆ, "Changes" ಟ್ಯಾಬ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಹೊಸ ಫೈಲ್‌ಗಳು ಪಟ್ಟಿ ಮಾಡಲ್ಪಟ್ಟಿರುವುದನ್ನು ನೋಡಬೇಕು.

<div class="tip-box">
  ನೀವು Claude ಗೆ ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಲು ಕೇಳಿದ್ದರೆ, ಕೆಳಗೆ ಬರೆದಿರುವ ಹಂತ 2 ಮತ್ತು 3 ಅನ್ನು ನೀವು ಬಿಟ್ಟುಬಿಡಬಹುದು.
</div>

#### ಹಂತ 2: ನಿಮ್ಮ ಬದಲಾವಣೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ

ಏನು ರಚಿಸಲಾಯಿತು ಅಥವಾ ಮಾರ್ಪಡಿಸಲಾಯಿತು ಎಂದು ನೋಡಲು ಫೈಲ್‌ಗಳ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ. ಬದಲಾಯಿಸಲಾದ ಎಲ್ಲಾ ಫೈಲ್‌ಗಳು ಪರಿಶೀಲಿಸಲ್ಪಟ್ಟಿರಬೇಕು.

#### ಹಂತ 3: ನಿಮ್ಮ ಬದಲಾವಣೆಗಳನ್ನು ಕಮಿಟ್ ಮಾಡಿ

1. ಕೆಳಗಿನ ಎಡ ಭಾಗದಲ್ಲಿರುವ "Summary" ಕ್ಷೇತ್ರದಲ್ಲಿ, ನೀವು ಮಾಡಿದ ಬದಲಾವಣೆಗಳನ್ನು ವಿವರಿಸುವ ಏನನ್ನಾದರೂ ಟೈಪ್ ಮಾಡಿ

1. **"Commit to branch"** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ

## ಉತ್ತಮ ಅಭ್ಯಾಸಗಳು

### 1. ಆಗಾಗ ಕಮಿಟ್ ಮಾಡಿ
ಅರ್ಥಪೂರ್ಣ ಕಮಿಟ್ ಸಂದೇಶಗಳೊಂದಿಗೆ ನಿಮ್ಮ ಕೆಲಸವನ್ನು ಆಗಾಗ ಉಳಿಸಿ. ಇದು ನೀವು ಮರಳಿ ನೋಡಬಹುದಾದ ಇತಿಹಾಸವನ್ನು ರಚಿಸುತ್ತದೆ.

### 2. ಕಮಿಟ್ ಮಾಡುವ ಮೊದಲು ಪರೀಕ್ಷಿಸಿ
ಕಮಿಟ್ ಮಾಡುವ ಮೊದಲು ಯಾವಾಗಲೂ ನಿಮ್ಮ ಬದಲಾವಣೆಗಳನ್ನು ಬ್ರೌಸರ್‌ನಲ್ಲಿ ವೀಕ್ಷಿಸಿ, ಅವು ನಿರೀಕ್ಷಿಸಿದಂತೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

### 3. ಸ್ಪಷ್ಟ ಕಮಿಟ್ ಸಂದೇಶಗಳನ್ನು ಬರೆಯಿರಿ
"updates" ಅಥವಾ "changes" ಬದಲಾಗಿ, ಇಂತಹವುಗಳನ್ನು ಬರೆಯಿರಿ:
- "Add contact form with validation"
- "Fix navigation menu alignment"
- "Update color scheme to blue"

ಇವುಗಳನ್ನು ಬರೆಯಲು ನೀವು Claude ಅನ್ನು ಸಹ ಕೇಳಬಹುದು.
