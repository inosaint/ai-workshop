ನಾವು ಅನುಸ್ಥಾಪನೆಗಳು ಮತ್ತು ಹೊಂದಾಣಿಕೆಗಳಿಗೆ ಧುಮುಕುವ ಮೊದಲು, AI ಏನು ಮಾಡಬಲ್ಲದು ಎಂಬುದನ್ನು **ಈಗಲೇ** ಅನುಭವಿಸೋಣ.

ChatGPT, Grok ಮತ್ತು Claude ಪಶ್ಚಿಮ ಜಗತ್ತಿನಲ್ಲಿ ಜನಪ್ರಿಯ LLM ಗಳಾಗಿವೆ. ಈ ಅಭ್ಯಾಸಕ್ಕಾಗಿ, ನಾವು Claude ಅನ್ನು ಬಳಸಲಿದ್ದೇವೆ, ಆದರೂ ನೀವು ನಿಮ್ಮ ಆಯ್ಕೆಯ LLM ನೊಂದಿಗೆ ಇದನ್ನು ಪ್ರಯತ್ನಿಸಬಹುದು.

## Claude ಎಂದರೇನು?

Claude ಅನ್ನು ಒಂದು **ಅತಿ-ಬುದ್ಧಿವಂತ ಸಹಾಯಕ** ಎಂದು ಭಾವಿಸಿ, ಅದನ್ನು ನೀವು ಸರಳ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ಚಾಟ್ ಇಂಟರ್ಫೇಸ್ ಮೂಲಕ ಮಾತನಾಡಬಹುದು. ಇಂದು ನೀವು Claude ಮತ್ತು ಇತರ LLM ಗಳನ್ನು ಬ್ಲಾಗ್ ಪೋಸ್ಟ್‌ಗಳನ್ನು ಸಂಪಾದಿಸುವುದರಿಂದ ಹಿಡಿದು ಚಿತ್ರಗಳನ್ನು ರಚಿಸುವವರೆಗೆ ಮತ್ತು ಸಂಪೂರ್ಣ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವವರೆಗೆ ವಿವಿಧ ಕಾರ್ಯಗಳಿಗೆ ಬಳಸಬಹುದು.

Claude ಗೆ **Artifacts** ಎಂಬ ವೈಶಿಷ್ಟ್ಯವಿದೆ, ಅದು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತಕ್ಷಣವೇ ವಸ್ತುಗಳನ್ನು ರಚಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುತ್ತದೆ - ಯಾವುದೇ ಹೊಂದಾಣಿಕೆ ಅಗತ್ಯವಿಲ್ಲ!

### ಹಂತ 1: Claude ತೆರೆಯಿರಿ

ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ [claude.ai](https://claude.ai/) ಗೆ ಹೋಗಿ ಮತ್ತು ಖಾತೆ ರಚಿಸಿ.

### ಹಂತ 2: Claude ಗೆ ಏನಾದರೂ ರಚಿಸಲು ಕೇಳಿ

ನೀವು ಲಾಗಿನ್ ಆದ ನಂತರ, ಇನ್‌ಪುಟ್ ಫೀಲ್ಡ್‌ನೊಂದಿಗೆ ಒಂದು ಇಂಟರ್ಫೇಸ್ ನೋಡಬಹುದು. Claude ಗೆ ಕೆಲವು ಸರಳ ಪ್ರಶ್ನೆಗಳನ್ನು ಕೇಳಿ ಪರಿಚಯ ಮಾಡಿಕೊಳ್ಳಿ.

ನೀವು ಸಿದ್ಧರಾದ ನಂತರ, ನಿಮ್ಮ ಮೊದಲ AI ಸಹಾಯಿತ artifact ರಚಿಸಲು ಮುಂದಾಗೋಣ.

ಈ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು Claude ಗೆ ಕಾಪಿ ಮಾಡಿ ಅಂಟಿಸಿ:

```
Can you create Tetris as a Claude Artifact?
```

**Enter** ಒತ್ತಿ ಮತ್ತು ನೋಡಿ!

ಗಮನಿಸಿ: ನೀವು ರಚಿಸಲು ಬಯಸುವ ಯಾವುದೇ ಇತರ ಸರಳ ಆಟವನ್ನು ಬಳಸಲು ಸ್ವತಂತ್ರರಾಗಿದ್ದೀರಿ ಅಥವಾ ಈ ಹೆಚ್ಚುವರಿ [ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು](#additional-prompts) ನೋಡಿ.

### ಹಂತ 3: ಮಾಯಾಜಾಲ ನೋಡಿ

ಕೆಲವೇ ಸೆಕೆಂಡ್‌ಗಳಲ್ಲಿ, Claude ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ನೇರವಾಗಿ **ಕಾರ್ಯನಿರ್ವಹಿಸುವ Tetris ಆಟ** ರಚಿಸುತ್ತದೆ!

### ಹಂತ 4: ಫಲಿತಾಂಶವನ್ನು ಪರಿಷ್ಕರಿಸಿ

ಫಲಿತಾಂಶ ನಿಮ್ಮ ತೃಪ್ತಿಗೆ ಅನುಗುಣವಾಗಿತ್ತೇ?
ಇಲ್ಲದಿದ್ದರೆ, ಬದಲಾವಣೆಗಳನ್ನು ಮಾಡಲು ಕೇಳಿ ಪ್ರಯತ್ನಿಸಿ.

ಉದಾ., ದೃಶ್ಯ ಶೈಲಿಯನ್ನು ಬದಲಾಯಿಸಲು ಅಥವಾ ಕೆಲವು ಮೋಜಿನ ಹೊಸ ಆಟದ ಅಂಶಗಳನ್ನು ಸೇರಿಸಲು ಕೇಳಬಹುದು.

✅ ನೀವು AI ನೊಂದಿಗೆ ನಿಮ್ಮ ಮೊದಲ ಅಪ್ಲಿಕೇಶನ್ ರಚಿಸಿದ್ದೀರಿ!
ಎಲ್ಲವೂ 5 ನಿಮಿಷಗಳೊಳಗೆ. ಹೆಚ್ಚು ಸಮಯದೊಂದಿಗೆ ನೀವು ಏನು ನಿರ್ಮಿಸಬಹುದು ಎಂದು ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ನೀವು ಈಗಷ್ಟೇ ಮಾಡಿದ್ದು ಈ ವರ್ಕ್‌ಶಾಪ್‌ನಲ್ಲಿ ನಾವು ಕಲಿಯುವ ಮೂಲ ವಿಷಯ:

1. **ನೀವು AI ಗೆ ಸೂಚನೆಗಳನ್ನು ನೀಡಿದಿರಿ** (ಒಂದು ಪ್ರಾಂಪ್ಟ್)
2. **AI ಉಪಯುಕ್ತವಾದ ಏನನ್ನಾದರೂ ರಚಿಸಿತು** (ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಕೋಡ್)
3. **ನೀವು ಅದನ್ನು ತಕ್ಷಣವೇ ಬಳಸಿದಿರಿ** (ಯಾವುದೇ ಸಂಕೀರ್ಣ ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದೆ)

ವ್ಯತ್ಯಾಸ? **Claude Artifacts** ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತಾತ್ಕಾಲಿಕವಾಗಿ ಚಲಿಸುತ್ತವೆ. ಈ ವರ್ಕ್‌ಶಾಪ್‌ನಲ್ಲಿ, ನೀವು ಕಲಿಯುವಿರಿ:

- ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿ **ಶಾಶ್ವತವಾಗಿ ಇರುವ** ಯೋಜನೆಗಳನ್ನು ರಚಿಸಿ
- **ನಿಮ್ಮ ಸ್ವಂತ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ** ವಿಷಯಗಳನ್ನು ನಿರ್ಮಿಸಿ
- ನಿಮ್ಮ ಕೋಡ್‌ನ ಮೇಲೆ **ಸಂಪೂರ್ಣ ನಿಯಂತ್ರಣ** ಹೊಂದಿರಿ
- ನಿಮ್ಮ ಸೃಷ್ಟಿಗಳನ್ನು **ಜಗತ್ತಿನ ಯಾರೊಂದಿಗಾದರೂ** ಹಂಚಿಕೊಳ್ಳಿ

## ಇನ್ನಷ್ಟಕ್ಕೆ ಸಿದ್ಧರೇ?

ಏನು ಸಾಧ್ಯ ಎಂದು ನೀವು ನೋಡಿದ ಈಗ, ನೀವು ಕಲ್ಪಿಸಬಹುದಾದ ಯಾವುದನ್ನಾದರೂ ನಿರ್ಮಿಸಲು ಅನುವು ಮಾಡಿಕೊಡುವ ಪರಿಕರಗಳನ್ನು ಹೊಂದಿಸೋಣ.
