<div class="tip-box">
  ನೀವು ಈಗಾಗಲೇ Github ನೊಂದಿಗೆ ಪರಿಚಿತರಾಗಿದ್ದರೆ ಮತ್ತು ಖಾತೆ ಹೊಂದಿದ್ದರೆ ಈ ವಿಭಾಗವನ್ನು ಬಿಟ್ಟುಬಿಡಬಹುದು.

</div>

GitHub ಎಂಬುದು ಡೆವಲಪರ್‌ಗಳು ತಮ್ಮ ಕೋಡ್ ಸಂಗ್ರಹಿಸುವ ಸ್ಥಳ. ಇದನ್ನು **ಕೋಡ್‌ಗಾಗಿ Google Drive** ಎಂದು ಭಾವಿಸಿ.

ಈ ವಿಭಾಗದಲ್ಲಿ, ನೀವು ಉಚಿತ GitHub ಖಾತೆಯನ್ನು ರಚಿಸುತ್ತೀರಿ, ಅದನ್ನು ಕಾರ್ಯಾಗಾರದ ಉಳಿದ ಭಾಗಕ್ಕೆ ಬಳಸುತ್ತೀರಿ.

### Git ಎಂದರೇನು?

**Git ನಿಮ್ಮ ಕೋಡ್‌ಗಾಗಿ ಒಂದು ಟೈಮ್ ಮಷಿನ್.**

ನೀವು ಹೀಗೆ ಫೈಲ್‌ಗಳನ್ನು ಉಳಿಸಿದ್ದನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಿ:
- `design_final.psd`
- `poster_final_v2.ai`
- `design_FINAL_FINAL.sketch`
- `design_FINAL_FINAL_actually_final.fig`

Git ಈ ಸಮಸ್ಯೆಯನ್ನು ಸೊಗಸಾಗಿ ಪರಿಹರಿಸುತ್ತದೆ. ಪ್ರತಿಗಳನ್ನು ರಚಿಸುವ ಬದಲು, Git ನೀವು ಮಾಡುವ ಪ್ರತಿಯೊಂದು ಬದಲಾವಣೆಯನ್ನೂ ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತದೆ. ನೀವು ಹೀಗೆ ಮಾಡಬಹುದು:
- ಯಾವುದೇ ಹಿಂದಿನ ಆವೃತ್ತಿಗೆ ಹಿಂದಿರುಗಬಹುದು
- ಏನು ಬದಲಾಯಿತು ಮತ್ತು ಯಾವಾಗ ಎಂದು ನೋಡಬಹುದು
- ಪರಸ್ಪರರ ಕೆಲಸವನ್ನು ತಿದ್ದಿ ಬರೆಯದೆ ಇತರರೊಂದಿಗೆ ಕೆಲಸ ಮಾಡಬಹುದು

## Git ಮತ್ತು GitHub: ವ್ಯತ್ಯಾಸವೇನು?

| Git                            | GitHub                              |
| ------------------------------ | ----------------------------------- |
| ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿರುವ ಸಾಫ್ಟ್‌ವೇರ್ | ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿರುವ ವೆಬ್‌ಸೈಟ್          |
| ಸ್ಥಳೀಯವಾಗಿ ಬದಲಾವಣೆಗಳನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತದೆ | ನಿಮ್ಮ ಕೋಡ್ ಅನ್ನು ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಸಂಗ್ರಹಿಸುತ್ತದೆ |
| ಉಚಿತ ಮತ್ತು ಮುಕ್ತ ಮೂಲ          | ಸಾರ್ವಜನಿಕ ಯೋಜನೆಗಳಿಗೆ ಉಚಿತ          |
| ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ | ಇಂಟರ್ನೆಟ್ ಅಗತ್ಯವಿದೆ                |

## ಪದಗಳ ಸಂಕ್ಷಿಪ್ತ ಪರಿಚಯ

ನಾವು ಮುಂದುವರಿಯುವ ಮೊದಲು, ನೀವು ಪರಿಚಿತರಾಗಿರಬೇಕಾದ ಕೆಲವು ಪದಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳೋಣ.

| ಪರಿಕಲ್ಪನೆ | ದೈನಂದಿನ ಉಪಮೆ |
|---|---|
|**GitHub**| Google Drive (ಕ್ಲೌಡ್) ತರಹ, ಆದರೆ ವಿಶೇಷವಾಗಿ ಕೋಡ್ ಯೋಜನೆಗಳಿಗಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ|
|**Repository** (repo)| ನಿಮ್ಮ ಯೋಜನಾ ಫೈಲ್‌ಗಳನ್ನು ಒಳಗೊಂಡ ಒಂದು ಫೋಲ್ಡರ್|
|**Commit**| ನಿಮ್ಮ ಕೆಲಸದ ಒಂದು ಆವೃತ್ತಿಯನ್ನು ಉಳಿಸುವುದು (ಟಿಪ್ಪಣಿ ಸಹಿತ "Save As" ತರಹ)|
|**Push**| ನಿಮ್ಮ ಉಳಿಸಿದ ಕೆಲಸವನ್ನು ಕ್ಲೌಡ್‌ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು|
|**Pull**| ಕ್ಲೌಡ್‌ನಿಂದ ಇತ್ತೀಚಿನ ಆವೃತ್ತಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು|

ಇವುಗಳನ್ನು ಈಗಲೇ ಕಂಠಪಾಠ ಮಾಡಬೇಕಿಲ್ಲ - ನಾವು ಬಳಸಿದ ನಂತರ ಇವು ಹೆಚ್ಚು ಅರ್ಥವಾಗುತ್ತವೆ!

## ನಿಮ್ಮ GitHub ಖಾತೆ ಹೊಂದಿಸುವುದು

### ಹಂತ 1:

**[github.com](https://github.com/)** ಗೆ ಹೋಗಿ ನಿಮ್ಮ ಸ್ವಂತ ಖಾತೆ ರಚಿಸಿ. ಖಾತೆ ರಚಿಸುವಾಗ ಒಳ್ಳೆಯ ಬಳಕೆದಾರ ಹೆಸರನ್ನು ಆರಿಸಿ. ನೀವು ಆರಿಸುವ ಬಳಕೆದಾರ ಹೆಸರು Github pages ಗಾಗಿ ಪೂರ್ವನಿಯೋಜಿತ ಹೆಸರಾಗಿ ಬಳಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ವೃತ್ತಿಪರವಾದದ್ದನ್ನು ಆರಿಸಿ (ನನ್ನಂತಲ್ಲ).

### ಹಂತ 2:

[Github Desktop](https://desktop.github.com) ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ನೀವು ಹೊಸದಾಗಿ ರಚಿಸಿದ ರುಜುವಾತುಗಳೊಂದಿಗೆ ಲಾಗಿನ್ ಮಾಡಿ.

### ಹಂತ 3:

Github Desktop ಬಳಸಿ [ಹೊಸ repository ರಚಿಸಿ](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop#creating-a-new-repository)(repo).

![Create a New Repository dialog](../../github-setup/new-repo-dialog.png)

ಈ ಸ್ವರೂಪದಲ್ಲಿ ಹೆಸರಿಸಿ: [username].github.io, ಇಲ್ಲಿ *username* ನಿಮ್ಮ github ಬಳಕೆದಾರ ಹೆಸರು. ಇದು ನಿಮ್ಮ ಉಚಿತ github ಡೊಮೈನ್ ಆಗಿ ಬಳಸಲಾಗುತ್ತದೆ. ದಯವಿಟ್ಟು ತಪ್ಪುಗಳನ್ನು ಮಾಡಬೇಡಿ, repository ಯ ಹೆಸರು ನಿಮ್ಮ github ಬಳಕೆದಾರ ಹೆಸರಿನ ಕಾಗುಣಿತ ಮತ್ತು ಅಕ್ಷರ ಗಾತ್ರದಲ್ಲಿ ಒಂದೇ ರೀತಿ ಇರಬೇಕು.

![Create a New Repository using Github Desktop](../../github-setup/new-repo.png)

Github Desktop ಮತ್ತು ಅದರ ಇಂಟರ್ಫೇಸ್ ಬಗ್ಗೆ ಹೆಚ್ಚು ತಿಳಿದುಕೊಳ್ಳಲು [Github ನ ಸಹಾಯ ಲೇಖನ](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop) ಗೆ ಹೋಗಬಹುದು.

### ಹಂತ 4:

Repo ಅನ್ನು ಪ್ರಕಟಿಸಿ. ಪ್ರಕಟಿಸುವಾಗ, ದಯವಿಟ್ಟು 'Keep this code private' ಚೆಕ್‌ಬಾಕ್ಸ್ ಅನ್ನು ಅನ್‌ಚೆಕ್ ಮಾಡಲು ನೆನಪಿಡಿ.

![Publish Repository dialog](../../github-setup/publish-repo.png)

### ಹಂತ 5:

Github.com ಗೆ ಹೋಗಿ ನಿಮ್ಮ ಹೊಸದಾಗಿ ರಚಿಸಿದ repository ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ ಮತ್ತು Settings ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಹಂತ 6:

![Configuring the Repo's Publish settings](../../github-setup/gh-pages.png)

ಎಡ nav ನಲ್ಲಿ pages ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ ಮತ್ತು '**Deploy from a Branch**' ಆಯ್ಕೆ ಮಾಡಿ, ನಂತರ **main / root** ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು '**Save**' ಕ್ಲಿಕ್ ಮಾಡಿ.

Repository ಪ್ರಕಟಿಸುವಾಗ 'Keep this code private' ಚೆಕ್‌ಬಾಕ್ಸ್ ಅನ್ನು ಅನ್‌ಚೆಕ್ ಮಾಡದಿದ್ದರೆ, ನೀವು ಹೆಚ್ಚುವರಿ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಬೇಕಾಗುತ್ತದೆ. ನೀವು Setting > General ಗೆ ಹೋಗಿ ನಂತರ ಪುಟದ ಕೆಳಗೆ 'Danger Zone' ವರೆಗೆ ಸ್ಕ್ರೋಲ್ ಮಾಡಿ 'Change repository visibility' ಅನ್ನು Private ನಿಂದ Public ಗೆ ಬದಲಾಯಿಸಬೇಕಾಗುತ್ತದೆ.

## ಮುಂದಿನ ಹಂತಗಳು

ನಿಮ್ಮ GitHub ಖಾತೆ ಸಿದ್ಧವಾಗಿದೆ. ಮುಂದಿನ ವಿಭಾಗದಲ್ಲಿ, ನಾವು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ Claude Code ಸ್ಥಾಪಿಸುತ್ತೇವೆ.
