ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ಜಗತ್ತಿನೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳುವ ಮೊದಲು, ಅದು ನಿಮ್ಮ ಸ್ವಂತ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಸರಿಯಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳೋಣ.

## "ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷಿಸುವುದು" ಎಂದರೇನು?

"ಸ್ಥಳೀಯ" ಎಂದರೆ ನಿಮ್ಮ ಸ್ವಂತ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ("ಕ್ಲೌಡ್" ಅಥವಾ "ಆನ್‌ಲೈನ್"ಗೆ ವಿರುದ್ಧವಾಗಿ).

ನೀವು ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷಿಸಿದಾಗ:
- ಕೇವಲ ನೀವು ಮಾತ್ರ ನೋಡಬಹುದು
- ಬದಲಾವಣೆಗಳು ತಕ್ಷಣವೇ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತವೆ
- ನೀವು ಸುರಕ್ಷಿತವಾಗಿ ವಿಷಯಗಳನ್ನು ಮುರಿಯಬಹುದು (ಬೇರೆ ಯಾರೂ ನೋಡುವುದಿಲ್ಲ!)
- ಉಚಿತ - ಯಾವುದೇ ಹೋಸ್ಟಿಂಗ್ ಅಗತ್ಯವಿಲ್ಲ

## Github Desktop ನೊಂದಿಗೆ Claude ನ ಬದಲಾವಣೆಗಳನ್ನು ಪ್ರವೇಶಿಸುವುದು

![](../../testing-locally/github-bar.png)
### ಹಂತ 1: GitHub Desktop ತೆರೆಯಿರಿ

GitHub Desktop ಗೆ ಬದಲಿಸಿ. ಮೇಲೆ ತೋರಿಸಿದ ಬಾರ್ ಅನ್ನು ನೀವು ಮೇಲ್ಭಾಗದಲ್ಲಿ ನೋಡಬೇಕು. ಎಡಭಾಗದ ವಿಭಾಗವು ನೀವು ಇರುವ ರೆಪೊಸಿಟರಿ ಆಗಿದೆ. ಮಧ್ಯದ ವಿಭಾಗವು ನೀವು ಇರುವ ಬ್ರ್ಯಾಂಚ್ ಮತ್ತು ಬಲಭಾಗದ ವಿಭಾಗವು 'ಕ್ರಿಯಾಶೀಲ' ವಿಭಾಗವಾಗಿದೆ.

### ಹಂತ 2: ನಿಮ್ಮ ಬ್ರ್ಯಾಂಚ್‌ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ

![](../../testing-locally/github-branch.png)

Claude ಕೆಲಸ ಮಾಡಿದ ಬ್ರ್ಯಾಂಚ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡಲು ಬ್ರ್ಯಾಂಚ್ ಸೆಲೆಕ್ಟರ್ ಅನ್ನು ಬಳಸಿ.

### Origin ನಿಂದ ಪುಲ್ ಮಾಡುವುದು

ಸರಿಯಾದ ಬ್ರ್ಯಾಂಚ್ ಆಯ್ಕೆ ಮಾಡಿದ ನಂತರ, "Pull Origin" ಗೆ ಒಂದು ಬಟನ್ ಕಾಣಿಸಬಹುದು. ಅದನ್ನು ಮಾಡಿ. ಇಲ್ಲದಿದ್ದರೆ '**Fetch Origin**' ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಅಪ್ಡೇಟ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸಲು ಅಪ್ಲಿಕೇಶನ್‌ಗಾಗಿ ಕಾಯಿರಿ.

## ಸ್ಥಳೀಯವಾಗಿ ಪರೀಕ್ಷಿಸುವುದು

Claude Code ನ ಕೆಲಸವನ್ನು ಪರೀಕ್ಷಿಸಲು ನೀವು ಎರಡು ವಿಧಾನಗಳಲ್ಲಿ ಆಯ್ಕೆ ಮಾಡಬಹುದು.

## ವಿಧಾನ 1: HTML ಫೈಲ್ ಅನ್ನು ನೇರವಾಗಿ ತೆರೆಯಿರಿ

ನೀವು ಒಂದು ಸರಳ ಸ್ಟಾಟಿಕ್ ಪ್ರಾಜೆಕ್ಟ್ ನಿರ್ಮಿಸಲು ಆಯ್ಕೆ ಮಾಡಿದ್ದರೆ, ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ವೀಕ್ಷಿಸಲು ಅತ್ಯಂತ ಸರಳ ಮಾರ್ಗವೆಂದರೆ ನಿಮ್ಮ ಫೈಲ್ ಫೈಂಡರ್‌ನಲ್ಲಿ ಫೋಲ್ಡರ್‌ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ **index.html** ಫೈಲ್ ತೆರೆಯುವುದು.

ಈ ಫೈಲ್ ತೆರೆಯುವುದರಿಂದ ಹೊಸ ಬ್ರೌಸರ್ ವಿಂಡೋ ತೆರೆಯಬೇಕು ಮತ್ತು ನೀವು ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ವೀಕ್ಷಿಸಲು ಸಾಧ್ಯವಾಗಬೇಕು.

<div class="tip-box">
  <strong>💡 ಸಲಹೆ:</strong> ಅಡ್ರೆಸ್ ಬಾರ್ <code>file:///path/to/your/file</code> ಎಂದು ತೋರಿಸುತ್ತದೆ. ಇದರ ಅರ್ಥ ನೀವು ಸ್ಥಳೀಯ ಫೈಲ್ ಅನ್ನು ವೀಕ್ಷಿಸುತ್ತಿದ್ದೀರಿ, ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿರುವ ವೆಬ್‌ಸೈಟ್ ಅಲ್ಲ.
</div>

## ವಿಧಾನ 2: ಸ್ಥಳೀಯ ಸರ್ವರ್ ಬಳಸಿ (ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ)

ಕೆಲವು ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ (ಡೇಟಾ ಲೋಡ್ ಮಾಡುವುದು ಅಥವಾ ಕೆಲವು JavaScript ಬಳಸುವಂತಹ) "ನಿಜವಾದ" ಸರ್ವರ್ ಅಗತ್ಯವಿದೆ. ಒಂದನ್ನು ಹೊಂದಿಸುವ ವಿಧಾನ ಇಲ್ಲಿದೆ:

### ಹಂತ 1: ಟರ್ಮಿನಲ್ ತೆರೆಯುವುದು

**Windows:**
1. Run ಡೈಲಾಗ್ ತೆರೆಯಲು `⊞ Win + R` ಒತ್ತಿರಿ
2. `cmd` ಟೈಪ್ ಮಾಡಿ ಮತ್ತು Enter ಒತ್ತಿರಿ
3. Command Prompt ವಿಂಡೋ ತೆರೆಯುತ್ತದೆ

**Mac:**
1. Spotlight ತೆರೆಯಲು `Cmd + Space` ಒತ್ತಿರಿ
2. `Terminal` ಟೈಪ್ ಮಾಡಿ ಮತ್ತು Enter ಒತ್ತಿರಿ
3. Terminal ವಿಂಡೋ ತೆರೆಯುತ್ತದೆ


<div class="tip-box">
  <strong>💡 ಟರ್ಮಿನಲ್ ಉಲ್ಲೇಖ:</strong> ಹೆಚ್ಚಿನ ಟರ್ಮಿನಲ್ ಕಮಾಂಡ್‌ಗಳು ಮತ್ತು ಸಲಹೆಗಳಿಗಾಗಿ, <a href="/reference/cheat-sheet/#terminal--command-line">ನಮ್ಮ ಚೀಟ್ ಶೀಟ್‌ನ ಟರ್ಮಿನಲ್ ವಿಭಾಗ</a> ಪರಿಶೀಲಿಸಿ.
</div>

### ಹಂತ 2: ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್‌ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ

ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ, ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ಗೆ ಹೋಗಲು `cd` (change directory) ಬಳಸಿ. ಪೂರ್ಣ ಫೋಲ್ಡರ್ ಪಾತ್‌ನೇಮ್ ಕಂಡುಹಿಡಿಯಲು ನೀವು ಸಿಸ್ಟಮ್‌ನ ಫೋಲ್ಡರ್ ಮಾಹಿತಿ ಮೆನು ಕ್ರಿಯೆಯನ್ನು ಬಳಸಬಹುದು.

**Windows:**
```bash
cd Documents\GitHub\my-project
```

**Mac:**
```bash
cd ~/Documents/GitHub/my-project
```

<div class="tip-box">
  <strong>💡 ಸಲಹೆ:</strong> "my-project" ಅನ್ನು ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ನ ನಿಜವಾದ ಹೆಸರಿನಿಂದ ಬದಲಾಯಿಸಿ. GitHub Desktop ಪ್ರಾಜೆಕ್ಟ್‌ಗಳನ್ನು ಎಲ್ಲಿ ಉಳಿಸುತ್ತದೆ ಎಂದು ಖಚಿತವಿಲ್ಲದಿದ್ದರೆ, GitHub Desktop → Preferences → Advanced → Repository storage location ಪರಿಶೀಲಿಸಿ.
</div>


ನೀವು ಸರಿಯಾದ ಸ್ಥಳದಲ್ಲಿದ್ದೀರಾ ಎಂದು ಪರಿಶೀಲಿಸಲು ಈ ಕೆಳಗಿನದನ್ನು ರನ್ ಮಾಡಿ:
- **Windows:** `dir`
- **Mac:** `ls`

ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಫೈಲ್‌ಗಳನ್ನು ನೀವು ನೋಡಬೇಕು (ಅಥವಾ ನೀವು ಈಗಷ್ಟೇ ರಚಿಸಿದ್ದರೆ ಖಾಲಿ ಫೋಲ್ಡರ್).

### ಹಂತ 3: ಸರ್ವರ್ ರನ್ ಮಾಡಿ
ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿದ ನಂತರ, ಈ ಕೆಳಗಿನ ಕಮಾಂಡ್ ರನ್ ಮಾಡಿ:

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2 (ಹಳೆಯ ಸಿಸ್ಟಮ್‌ಗಳು):**
```bash
python -m SimpleHTTPServer 8000
```

ಇದು ಪೋರ್ಟ್ 8000 ನಲ್ಲಿ ಸ್ಥಳೀಯ ಸರ್ವರ್ ಅನ್ನು ಹೊಂದಿಸಬೇಕು ಮತ್ತು ಅದು ರನ್ ಆಗುತ್ತಿರುವಾಗ, ಸರಿಯಾದ URL ಗೆ ನಿಮ್ಮ ಬ್ರೌಸರ್ ಅನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತೆರೆಯಬೇಕು. ಇಲ್ಲದಿದ್ದರೆ ಕೆಳಗಿನ URL ಬಳಸಿ.
```
http://localhost:8000
```

ಟರ್ಮಿನಲ್ ವಿಂಡೋದಲ್ಲಿ ಯಾವುದೇ ದೋಷ ಕಂಡುಬಂದರೆ, ಆ ದೋಷವನ್ನು Claude ನ ಚಾಟ್‌ಗೆ ನಕಲಿಸಿ ಮತ್ತು ಅಂಟಿಸಿ, Claude ನೀವು ಏನು ಮಾಡಬೇಕು ಎಂದು ಹೇಳಲು ಸಾಧ್ಯವಾಗುತ್ತದೆ.

## ಪರೀಕ್ಷಾ ಪಟ್ಟಿ

ನಿಮ್ಮ ಪ್ರಾಜೆಕ್ಟ್ ಮೂಲಕ ಹೋಗಿ ಈ ವಿಷಯಗಳನ್ನು ಪರಿಶೀಲಿಸಿ:

### ದೃಶ್ಯ ಪರಿಶೀಲನೆಗಳು

- [ ] ಎಲ್ಲವೂ ಪರದೆಯ ಮೇಲೆ ಕಾಣಿಸುತ್ತಿದೆಯೇ?
- [ ] ಬಣ್ಣಗಳು ಸರಿಯಾಗಿ ಕಾಣಿಸುತ್ತಿವೆಯೇ?
- [ ] ಪಠ್ಯ ಓದಬಹುದಾದಷ್ಟು ಸ್ಪಷ್ಟವಾಗಿದೆಯೇ (ತುಂಬಾ ಚಿಕ್ಕದು/ದೊಡ್ಡದು ಅಲ್ಲ)?
- [ ] ಚಿತ್ರಗಳು ಸರಿಯಾಗಿ ಲೋಡ್ ಆಗುತ್ತಿವೆಯೇ?

### ಸಂವಾದಾತ್ಮಕ ಪರಿಶೀಲನೆಗಳು

- [ ] ಬಟನ್‌ಗಳನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ಏನಾದರೂ ಆಗುತ್ತಿದೆಯೇ?
- [ ] ಲಿಂಕ್‌ಗಳು ಸರಿಯಾದ ಸ್ಥಳಗಳಿಗೆ ಕರೆದೊಯ್ಯುತ್ತಿವೆಯೇ?
- [ ] ಫಾರ್ಮ್‌ಗಳು ಇನ್‌ಪುಟ್ ಸ್ವೀಕರಿಸುತ್ತಿವೆಯೇ?
- [ ] ಅನಿಮೇಶನ್‌ಗಳು/ಎಫೆಕ್ಟ್‌ಗಳು ಕೆಲಸ ಮಾಡುತ್ತಿವೆಯೇ?

### ರೆಸ್ಪಾನ್ಸಿವ್ ಪರಿಶೀಲನೆಗಳು (ಮೊಬೈಲ್-ಸ್ನೇಹಿ)

ಹೆಚ್ಚಿನ ಬ್ರೌಸರ್‌ಗಳು ಮೊಬೈಲ್ ಸಾಧನಗಳನ್ನು ಅನುಕರಿಸಲು ನಿಮಗೆ ಅನುಮತಿಸುತ್ತವೆ:

1. ಪೇಜ್‌ನ ಯಾವುದೇ ಸ್ಥಳದಲ್ಲಿ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ
2. **"Inspect"** ಅಥವಾ **"Inspect Element"** ಕ್ಲಿಕ್ ಮಾಡಿ
3. **ಡಿವೈಸ್ ಟಾಗಲ್** ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ (ಫೋನ್/ಟ್ಯಾಬ್ಲೆಟ್‌ನಂತೆ ಕಾಣಿಸುತ್ತದೆ)
4. ಪರೀಕ್ಷಿಸಲು ವಿವಿಧ ಸಾಧನಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡಿ

## ಸಮಸ್ಯೆ ಕಂಡುಬಂತೇ? ಸರಿಪಡಿಸಿ!

ಏನಾದರೂ ಸರಿಯಾಗಿಲ್ಲದಿದ್ದಾಗ, ನಿಮಗೆ ಆಯ್ಕೆಗಳಿವೆ:

### ಆಯ್ಕೆ 1: Claude Code ಅನ್ನು ಕೇಳಿ

Claude Code ಗೆ ಹಿಂತಿರುಗಿ ಮತ್ತು ಸಮಸ್ಯೆಯನ್ನು ವಿವರಿಸಿ:

```text
When I click "Submit", nothing happens. The form should
show a success message.
```

ಅಥವಾ ದೋಷದ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ತೆಗೆದು ನೀವು ಅದನ್ನು ಹೇಗೆ ಸರಿಪಡಿಸಲು ಬಯಸುತ್ತೀರಿ ಎಂದು ವಿವರಿಸಿ.

```text
The color contrast of the button on the homepage isn't as per accessibility guidelines. Can you fix it?
```

### ಆಯ್ಕೆ 2: ನೀವೇ ಡೀಬಗ್ ಮಾಡಿ

ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನ ಡೆವಲಪರ್ ಟೂಲ್‌ಗಳನ್ನು ತೆರೆಯಿರಿ:

- **Windows**: `F12` ಅಥವಾ `Ctrl + Shift + I` ಒತ್ತಿರಿ
- **Mac**: `Cmd + Option + I` ಒತ್ತಿರಿ

**Console** ಟ್ಯಾಬ್‌ನಲ್ಲಿ ಕೆಂಪು ದೋಷ ಸಂದೇಶಗಳನ್ನು ನೋಡಿ. ಇವು ಏನು ತಪ್ಪಾಯಿತು ಎಂದು ನಿಮಗೆ ತಿಳಿಸುತ್ತವೆ. ಅವು ಏನು ಅರ್ಥ ಎಂದು ನಿಮಗೆ ಅರ್ಥವಾಗದಿದ್ದರೆ, ಈ ಸಂದೇಶಗಳನ್ನು Claude ಚಾಟ್‌ಗೆ ಅಂಟಿಸಿ ಮತ್ತು ಅದು ಮುಂದಿನ ಹಂತಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳಲು ನಿಮಗೆ ಸಹಾಯ ಮಾಡುತ್ತದೆ.

## ತೊಂದರೆ ನಿವಾರಣೆ

### ಚಿತ್ರಗಳು ಲೋಡ್
