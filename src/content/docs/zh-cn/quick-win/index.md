在我们深入了解安装和设置之前，让我们**立刻**体验一下 AI 能做什么。

ChatGPT、Grok 和 Claude 是西方世界最流行的大语言模型（LLM）。在本练习中，我们将使用 Claude，当然你也可以用你喜欢的 LLM 来尝试。

## 什么是 Claude？

把 Claude 想象成一个**超级智能的助手**，你可以通过聊天界面用自然语言与它交流。如今，你可以使用 Claude 和其他 LLM 完成各种任务，从编辑博客文章到生成图片，甚至构建完整的应用程序。

Claude 有一个叫做 **Artifacts** 的功能，可以让你直接在浏览器中即时创建内容——无需任何设置！

### 第一步：打开 Claude

在浏览器中访问 [claude.ai](https://claude.ai/)，并创建一个账户。

### 第二步：让 Claude 创建一些东西

登录后，你应该能看到一个带有输入框的界面。先尝试向 Claude 提一些简单的问题，熟悉一下操作。

准备好之后，让我们来创建你的第一个 AI 辅助 Artifact。

将以下提示词复制并粘贴到 Claude 中：

```
Can you create Tetris as a Claude Artifact?
```

按下 **Enter**，见证奇迹！

注意：你也可以选择任何你想创建的其他简单游戏，或者查看这些额外的[提示词](#additional-prompts)。

### 第三步：见证魔法

几秒钟之内，Claude 就会在你的浏览器中创建一个**可运行的俄罗斯方块游戏**！

![Claude 在浏览器中施展魔法](../../quick-win/tetris.png)

### 第四步：对结果进行迭代

结果令你满意吗？
如果不满意，可以尝试让它进行修改。

例如，你可以让它更改视觉风格，或者添加一些有趣的新游戏元素。

✅ 你刚刚用 AI 创建了你的第一个应用！
这一切都在 5 分钟内完成。想象一下，有了更多时间，你能构建出什么。

## 额外提示词

以下是一些可以让 Claude 创建的有趣内容：

### 番茄计时器

```
Create a Pomodoro timer with 25-minute work sessions and 5-minute breaks.
Add start, pause, and reset buttons. Show the time in a large, easy-to-read format.
```

### 配色方案生成器

```
Create a color palette generator that shows 5 harmonious colors.
Add a "Generate New Palette" button. Show the hex codes for each color and let me click to copy them.
```

### 一个简单的游戏

```
Create a simple memory card matching game with 8 pairs of cards. When I click two cards, show if they match. Track my number of moves.
```

## 为什么这很重要

你刚才所做的，正是我们在本工作坊中将要学习的核心内容：

1. **你给了 AI 指令**（一个提示词）
2. **AI 创建了有用的东西**（可以运行的代码）
3. **你立即使用了它**（无需复杂的设置）

区别在哪里？**Claude Artifacts** 只是暂时运行在你的浏览器中。在本工作坊中，你将学会：

- 创建**永久存在**于互联网上的项目
- 在**自己的电脑**上构建东西
- 对你的代码拥有**完全的控制权**
- 将你的创作分享给**世界上的任何人**
