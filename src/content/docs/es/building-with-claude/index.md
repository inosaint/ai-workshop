¡Este es el momento que has estado esperando! Usemos Claude Code para construir tu proyecto.

### Paso 1: Abre un nuevo chat de Claude Code

![New Chat Setup](../../building-with-claude/new-project.png)

1. Elige el repositorio en el que quieres que Claude trabaje. Ej., username/username.github.io
2. Selecciona el entorno Cloud predeterminado
3. Pega tu prompt
4. (opcional) Añade imágenes de referencia de diseño


### Paso 2: Observa y Aprende

Claude Code:

1. **Planificará** - Pensará en el mejor enfoque
2. **Creará archivos** - Generará archivos HTML, CSS y JavaScript
3. **Explicará** - Te dirá qué está haciendo y por qué

![How the mostly one-sided Chat conversation would look like](../../building-with-claude/example-convo.png)

<div class="warning-box">
  <strong>⚠️ ¡Ten paciencia!</strong> Los proyectos complejos pueden tardar uno o dos minutos. No interrumpas a Claude Code mientras está trabajando.
</div>


### Paso 3: Revisa lo que se Creó

![Claude will push it's changes to a branch](../../building-with-claude/claude-branch.png)

Después de que Claude Code termine, veamos qué archivos se crearon. Claude Code habrá creado una nueva rama y enviado su trabajo a esa rama. Necesitarás *obtener* esos cambios en tu sistema local para revisarlos.

## Solución de Problemas

### Repositorio de Github no instalado

![Github app not installed](../../building-with-claude/github-connection.png)

Necesitarás volver a conectar la integración de Github y seleccionar el repositorio en el que estás trabajando.
