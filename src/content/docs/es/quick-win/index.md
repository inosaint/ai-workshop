Antes de sumergirnos en instalaciones y configuraciones, experimentemos lo que la IA puede hacer **ahora mismo**.

ChatGPT, Grok y Claude son los LLMs más populares en el mundo occidental. Para este ejercicio usaremos Claude, aunque puedes intentarlo con el LLM de tu elección.

## ¿Qué es Claude?

Piensa en Claude como un **asistente superinteligente** con el que puedes hablar a través de una interfaz de chat en español o inglés sencillo. Hoy puedes usar Claude y otros LLMs para realizar una variedad de tareas, desde editar publicaciones de blog hasta generar imágenes e incluso construir aplicaciones completas.

Claude tiene una función llamada **Artifacts** que te permite crear cosas instantáneamente en tu navegador, ¡sin ninguna configuración!

### Paso 1: Abre Claude

Ve a [claude.ai](https://claude.ai/) en tu navegador y crea una cuenta.

### Paso 2: Pídele a Claude que Cree Algo

Una vez que inicies sesión, deberías ver una interfaz con un campo de entrada. Intenta hacerle a Claude algunas consultas sencillas para familiarizarte.

Cuando estés listo, vamos a crear tu primer artefacto con asistencia de IA.

Copia y pega este prompt en Claude:

```
Can you create Tetris as a Claude Artifact?
```

¡Presiona **Enter** y observa!

Nota: siéntete libre de usar cualquier otro juego sencillo que quieras crear, o echa un vistazo a estos [Prompts adicionales](#prompts-adicionales).

### Paso 3: Observa la Magia

En segundos, ¡Claude creará un **juego de Tetris funcional** directamente en tu navegador!

![Claude haciendo su magia en el navegador](../../quick-win/tetris.png)

### Paso 4: Itera sobre el Resultado

¿El resultado fue de tu agrado?
Si no, intenta pedirle que haga cambios.

Por ejemplo, puedes pedirle que cambie el estilo visual o que añada nuevos elementos divertidos al juego.

✅ ¡Acabas de crear tu primera aplicación con IA!
Todo en menos de 5 minutos. Imagina lo que puedes construir con más tiempo.

## Prompts Adicionales

Aquí hay algunas cosas divertidas que puedes pedirle a Claude que cree:

### Un Temporizador Pomodoro

```
Create a Pomodoro timer with 25-minute work sessions and 5-minute breaks.
Add start, pause, and reset buttons. Show the time in a large, easy-to-read format.
```

### Un Generador de Paletas de Colores

```
Create a color palette generator that shows 5 harmonious colors.
Add a "Generate New Palette" button. Show the hex codes for each color and let me click to copy them.
```

### Un Juego Sencillo

```
Create a simple memory card matching game with 8 pairs of cards. When I click two cards, show if they match. Track my number of moves.
```

## Por Qué Esto Importa

Lo que acabas de hacer es el núcleo de lo que aprenderemos en este taller:

1. **Le diste instrucciones a la IA** (un prompt)
2. **La IA creó algo útil** (código que funciona)
3. **Lo usaste de inmediato** (sin configuraciones complejas)

¿La diferencia? **Claude Artifacts** se ejecuta temporalmente en tu navegador. En este taller, aprenderás a:

- Crear proyectos que **vivan permanentemente** en internet
- Construir cosas **en tu propia computadora**
- Tener **control total** sobre tu código
- Compartir tus creaciones con **cualquier persona en el mundo**
