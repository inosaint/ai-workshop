## 这份指南适合谁？

正如上面所说，这份指南面向所有刚刚起步、没有任何编程经验的初学者。

当我在 [2025 年 11 月开始 vibe coding](http://kenneth.dsouza.im/writing/vibe-coding/) 并把项目分享给朋友时，很多人表达了尝试 vibe coding 的兴趣，但我发现市面上几乎没有能帮助大家独立上手的资源。大多数教程，包括官方文档，往往是为中级或高级用户编写的。

确实存在一些基于 AI 的 vibe coding 平台，比如 Replit 和 Figma Make，但它们或多或少会把你锁定在自己的封闭平台内。因此，我决定根据自己的 vibe coding 方法写一份简单的指南（也许是一本"缺失的手册"？），希望能帮助新用户感受 vibe coding 的魅力，迈出自己动手构建的第一步。

## 你需要准备什么

在开始之前，请确保你拥有：

- ✅ 一台电脑（Windows 或 Mac 均可）
- ✅ 网络连接
- ✅ 约 3 小时的专注时间
- ✅ 好奇心与耐心！

就这些。无需特殊软件，无需编程知识，无需任何经验。


## 关于犯错这件事

这里有一个经验丰富的开发者都知道的秘密：

> **每个人都会犯错。每时每刻，无一例外。**

当出现问题时（这是必然的），那不是失败——那是成长。每一条报错信息都是一条线索，每一个 bug 都是一道待解的谜题。

本工作坊提供了一个 [故障排查](/troubleshooting/) 章节，涵盖常见问题的解决方法。
