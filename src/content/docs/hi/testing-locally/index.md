अपने प्रोजेक्ट को दुनिया के साथ साझा करने से पहले, आइए सुनिश्चित करें कि यह आपके अपने कंप्यूटर पर ठीक से काम करता है।

## "स्थानीय रूप से परीक्षण करना" का क्या अर्थ है?

"स्थानीय" का अर्थ है आपके अपने कंप्यूटर पर (जैसा कि "क्लाउड" या "ऑनलाइन" के विपरीत है)।

जब आप स्थानीय रूप से परीक्षण करते हैं:
- केवल आप इसे देख सकते हैं
- परिवर्तन तुरंत दिखाई देते हैं
- आप सुरक्षित रूप से चीजें तोड़ सकते हैं (कोई और नहीं देखेगा!)
- यह मुफ़्त है - किसी होस्टिंग की ज़रूरत नहीं

## GitHub Desktop के साथ Claude के परिवर्तनों तक पहुंचना

![](../../testing-locally/github-bar.png)
### चरण 1: GitHub Desktop खोलें

GitHub Desktop पर जाएं। आपको ऊपर उल्लिखित बार दिखनी चाहिए। सबसे बाईं ओर का भाग वह रिपॉजिटरी है जिस पर आप हैं। बीच का भाग वह ब्रांच है जिस पर आप हैं और सबसे दाईं ओर का भाग 'कार्योन्मुख' अनुभाग है।

### चरण 2: अपनी ब्रांच पर जाएं

![](../../testing-locally/github-branch.png)

ब्रांच सेलेक्टर का उपयोग करके उस ब्रांच को चुनें जिस पर Claude ने काम किया।

### Origin से Pull करना

सही ब्रांच चुनने के बाद, आपको "Pull Origin" का बटन दिख सकता है। वह करें। यदि नहीं दिखे तो '**Fetch Origin**' पर क्लिक करें और ऐप को अपडेट जांचने के लिए प्रतीक्षा करें।

## स्थानीय रूप से परीक्षण करना

Claude Code के काम को परीक्षण करने के लिए आप दो तरीकों में से चुन सकते हैं।

## तरीका 1: सीधे HTML फ़ाइल खोलें

यदि आपने एक सरल स्टैटिक प्रोजेक्ट बनाना चुना है, तो अपने प्रोजेक्ट को देखने का सबसे आसान तरीका है कि अपने फ़ाइल फाइंडर में फ़ोल्डर में जाएं और **index.html** फ़ाइल खोलें।

इस फ़ाइल को खोलने पर एक नई ब्राउज़र विंडो खुलनी चाहिए और आप अपना प्रोजेक्ट देख सकते हैं।

<div class="tip-box">
  <strong>💡 सुझाव:</strong> एड्रेस बार में <code>file:///path/to/your/file</code> जैसा कुछ दिखेगा। इसका मतलब है कि आप एक स्थानीय फ़ाइल देख रहे हैं, इंटरनेट पर कोई वेबसाइट नहीं।
</div>

## तरीका 2: स्थानीय सर्वर का उपयोग करें (अनुशंसित)

कुछ सुविधाओं (जैसे डेटा लोड करना या कुछ JavaScript का उपयोग करना) के लिए एक "असली" सर्वर की आवश्यकता होती है। इसे सेट करने का तरीका यहां दिया गया है:

### चरण 1: Terminal खोलें

**Windows:**
1. Run डायलॉग खोलने के लिए `⊞ Win + R` दबाएं
2. `cmd` टाइप करें और Enter दबाएं
3. Command Prompt विंडो खुल जाएगी

**Mac:**
1. Spotlight खोलने के लिए `Cmd + Space` दबाएं
2. `Terminal` टाइप करें और Enter दबाएं
3. Terminal विंडो खुल जाएगी


<div class="tip-box">
  <strong>💡 Terminal संदर्भ:</strong> अधिक terminal कमांड और सुझावों के लिए, <a href="/reference/cheat-sheet/#terminal--command-line">हमारी Cheat Sheet का Terminal अनुभाग</a> देखें।
</div>

### चरण 2: अपने प्रोजेक्ट पर जाएं

Terminal में, अपने प्रोजेक्ट फ़ोल्डर तक जाने के लिए `cd` (change directory) का उपयोग करें। पूरा फ़ोल्डर पाथनेम खोजने के लिए आप सिस्टम के फ़ोल्डर सूचना मेनू एक्शन का उपयोग कर सकते हैं।

**Windows:**
```bash
cd Documents\GitHub\my-project
```

**Mac:**
```bash
cd ~/Documents/GitHub/my-project
```

<div class="tip-box">
  <strong>💡 सुझाव:</strong> "my-project" को अपने वास्तविक प्रोजेक्ट फ़ोल्डर के नाम से बदलें। यदि आप निश्चित नहीं हैं कि GitHub Desktop प्रोजेक्ट कहाँ सहेजता है, तो GitHub Desktop → Preferences → Advanced → Repository storage location जांचें।
</div>


यह सत्यापित करने के लिए कि आप सही जगह पर हैं, यह चलाएं:
- **Windows:** `dir`
- **Mac:** `ls`

आपको अपनी प्रोजेक्ट फ़ाइलें दिखनी चाहिए (या एक खाली फ़ोल्डर यदि आपने इसे अभी बनाया है)।

### चरण 3: सर्वर चलाएं
अब जब आप Terminal में अपने प्रोजेक्ट फ़ोल्डर में पहुंच गए हैं, तो निम्नलिखित कमांड चलाएं:

**Python 3:**
```bash
python -m http.server 8000
```

**Python 2 (पुराने सिस्टम):**
```bash
python -m SimpleHTTPServer 8000
```

यह port 8000 पर स्थानीय सर्वर सेटअप करेगा और जब यह चल रहा होगा, तो यह स्वचालित रूप से आपके ब्राउज़र को सही URL पर खोलना चाहिए। यदि नहीं खुलता तो नीचे दिए गए URL का उपयोग करें।
```
http://localhost:8000
```

यदि Terminal विंडो में कोई त्रुटि आती है, तो उस त्रुटि को कॉपी करके Claude की chat में पेस्ट करें और Claude आपको बता सकेगा कि आपको क्या करना है।

## परीक्षण चेकलिस्ट

अपने प्रोजेक्ट की जांच करें और इन बातों की पुष्टि करें:

### दृश्य जांच

- [ ] क्या सब कुछ स्क्रीन पर दिख रहा है?
- [ ] क्या रंग सही दिखते हैं?
- [ ] क्या टेक्स्ट पढ़ने योग्य है (बहुत छोटा/बड़ा नहीं)?
- [ ] क्या इमेज सही तरह से लोड होती हैं?

### इंटरैक्टिव जांच

- [ ] क्या बटन क्लिक करने पर कुछ करते हैं?
- [ ] क्या लिंक सही जगहों पर जाते हैं?
- [ ] क्या फॉर्म इनपुट स्वीकार करते हैं?
- [ ] क्या एनिमेशन/इफेक्ट काम करते हैं?

### रिस्पॉन्सिव जांच (मोबाइल-अनुकूल)

अधिकांश ब्राउज़र आपको मोबाइल डिवाइस का अनुकरण करने देते हैं:

1. पेज पर कहीं भी राइट-क्लिक करें
2. **"Inspect"** या **"Inspect Element"** पर क्लिक करें
3. **device toggle** आइकन पर क्लिक करें (फोन/टैबलेट जैसा दिखता है)
4. परीक्षण करने के लिए विभिन्न डिवाइस चुनें

## कोई समस्या मिली? इसे ठीक करें!

जब कुछ सही नहीं होता, तो आपके पास विकल्प हैं:

### विकल्प 1: Claude Code से पूछें

Claude Code पर वापस जाएं और समस्या का वर्णन करें:

```text
When I click "Submit", nothing happens. The form should
show a success message.
```

या त्रुटि का स्क्रीनशॉट लें और वर्णन करें कि आप इसे कैसे ठीक करना चाहते हैं।

```text
The color contrast of the button on the homepage isn't as per accessibility guidelines. Can you fix it?
```

### विकल्प 2: खुद डीबग करें

अपने ब्राउज़र के developer tools खोलें:

- **Windows**: `F12` या `Ctrl + Shift + I` दबाएं
- **Mac**: `Cmd + Option + I` दबाएं

**Console** टैब में लाल त्रुटि संदेश देखें। ये आपको बताते हैं कि क्या गलत हुआ। यदि आप समझ नहीं पाते कि उनका क्या अर्थ है, तो इन संदेशों को Claude chat में पेस्ट करें और वह आपको अगले कदम उठाने में मदद कर सकेगा।

## समस्या निवारण

### इमेज लोड नहीं हो रहीं

**संभावित कारण:**
- गलत फ़ाइल पाथ (`src` एट्रिब्यूट जांचें)
- फ़ाइल गलत फ़ोल्डर में है
- फ़ाइलनाम में टाइपो (केस मायने रखता है!)

**समाधान:** सुनिश्चित करें कि आपका इमेज पाथ बिल्कुल वहीं मेल खाता है जहां फ़ाइल है:
```html
<!-- यदि इमेज उसी फ़ोल्डर में है -->
<img src="../../testing-locally/photo.jpg" alt="Photo">

<!-- यदि इमेज "images" फ़ोल्डर में है -->
<img src="../../testing-locally/images/photo.jpg" alt="Photo">
```

### CSS लागू नहीं हो रही

**संभावित कारण:**
- CSS फ़ाइल HTML में लिंक नहीं है
- CSS लिंक पाथ में टाइपो
- ब्राउज़र ने पुराना वर्शन कैश किया हुआ है

**समाधान:** अपने HTML के `<head>` अनुभाग की जांच करें:
```html
<link rel="stylesheet" href="styles.css">
```

हार्ड रिफ्रेश करें: `Ctrl + Shift + R` (Windows) या `Cmd + Shift + R` (Mac)

### JavaScript काम नहीं कर रही

**संभावित कारण:**
- स्क्रिप्ट फ़ाइल लिंक नहीं है
- HTML एलिमेंट के अस्तित्व में आने से पहले स्क्रिप्ट लोड हुई
- कोड में सिंटैक्स त्रुटि

**समाधान:** Console में त्रुटियां जांचें, और सुनिश्चित करें कि आपकी स्क्रिप्ट body के अंत में है:
```html
<body>
  <!-- आपकी सामग्री -->

  <script src="script.js"></script>  <!-- स्क्रिप्ट को अंत में रखें! -->
</body>
```
