अब आता है मज़ेदार हिस्सा - यह तय करना कि क्या बनाना है!

इस वर्कशॉप के दौरान, आप तीन प्रोजेक्ट विचारों में से चुन सकते हैं, या अपना खुद का ला सकते हैं:

| प्रोजेक्ट | विवरण |
|---------|-------------|
| Personal Portfolio | एक खूबसूरत one-page वेबसाइट जो आप कौन हैं यह दर्शाती है |
| Interactive Quiz | एक मज़ेदार गेम जो ज्ञान परखता है और परिणाम दिखाता है |
| Habit Tracker | एक सरल ऐप जो रोज़ाना की आदतें ट्रैक करता है और आपकी प्रगति दिखाता है |
| आपका खुद का विचार | कुछ भी जो आप सोच सकते हैं! |

सभी रास्ते एक ही मंज़िल पर ले जाते हैं: एक काम करने वाला प्रोजेक्ट जिसे आप दिखा सकें!

## विकल्प 4: अपना खुद का विचार बनाएं!

मन में कुछ और है? अपना प्रोजेक्ट प्रॉम्प्ट बनाने के लिए हमारे Prompt Builder का उपयोग करें!

<div className="prompt-editor">
  <h3>✨ Prompt Builder</h3>

  <div className="prompt-fields">
    <div className="prompt-field">
      <label htmlFor="projectType">प्रोजेक्ट किस प्रकार का है?</label>
      <select id="projectType">
        <option value="">एक प्रकार चुनें...</option>
        <option value="website">Website / Landing Page</option>
        <option value="game">Game</option>
        <option value="tool">Utility / Tool</option>
        <option value="dashboard">Dashboard</option>
        <option value="other">अन्य</option>
      </select>
    </div>

    <div className="prompt-field">
      <label htmlFor="projectIdea">अपना विचार बताएं (1-2 वाक्य)</label>
      <textarea id="projectIdea" placeholder="जैसे, एक recipe organizer जहाँ मैं अपनी पसंदीदा recipes सहेज और खोज सकता हूँ"></textarea>
    </div>

    <div className="prompt-field">
      <label htmlFor="projectFeatures">मुख्य विशेषताएं (comma से अलग करें)</label>
      <input type="text" id="projectFeatures" placeholder="जैसे, search, favorites, categories, dark mode" />
    </div>

    <div className="prompt-field">
      <label htmlFor="projectColors">रंग की प्राथमिकता (वैकल्पिक)</label>
      <input type="text" id="projectColors" placeholder="जैसे, blue and white, dark theme, colorful" />
    </div>
  </div>

  <button id="generateBtn" className="prompt-button">
    मेरा प्रॉम्प्ट बनाएं
  </button>

  <div id="generatedPrompt" className="generated-prompt">
    <label>आपका कस्टम प्रॉम्प्ट:</label>
    <div className="prompt-output-wrapper">
      <pre id="promptOutput"></pre>
      <button id="copyBtn" className="copy-button">
        कॉपी करें
      </button>
    </div>
  </div>
</div>

<script>
{`
(function() {
  function init() {
    const generateBtn = document.getElementById('generateBtn');
    const copyBtn = document.getElementById('copyBtn');

    if (generateBtn) {
      generateBtn.addEventListener('click', generatePrompt);
    }

    if (copyBtn) {
      copyBtn.addEventListener('click', copyPrompt);
    }
  }

  function generatePrompt() {
    const type = document.getElementById('projectType').value;
    const idea = document.getElementById('projectIdea').value;
    const features = document.getElementById('projectFeatures').value;
    const colors = document.getElementById('projectColors').value;

    if (!idea) {
      alert('Please describe your project idea!');
      return;
    }

    let prompt = 'Create a ' + (type || 'web project') + ':\\n\\n';
    prompt += 'Main concept: ' + idea + '\\n\\n';
    prompt += 'Features to include:\\n';

    if (features) {
      features.split(',').forEach(feature => {
        prompt += '- ' + feature.trim() + '\\n';
      });
    } else {
      prompt += '- [Add your key features here]\\n';
    }

    prompt += '\\nAdditional requirements:\\n';
    if (colors) {
      prompt += '- Color scheme: ' + colors + '\\n';
    }
    prompt += '- Mobile-responsive design\\n';
    prompt += '- Clean, modern UI\\n';
    prompt += '- Use HTML, CSS, and vanilla JavaScript only\\n';
    prompt += '- Include helpful comments in the code';

    document.getElementById('promptOutput').textContent = prompt;
    document.getElementById('generatedPrompt').classList.add('show');
  }

  function copyPrompt() {
    const prompt = document.getElementById('promptOutput').textContent;
    navigator.clipboard.writeText(prompt).then(() => {
      const btn = document.getElementById('copyBtn');
      btn.textContent = 'Copied!';
      btn.style.background = '#10b981';
      setTimeout(() => {
        btn.textContent = 'Copy';
        btn.style.background = 'var(--sl-color-accent)';
      }, 2000);
    });
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', init);
  } else {
    init();
  }
})();
`}
</script>

## आगे क्या होता है?

एक बार जब आपने अपना प्रोजेक्ट चुन (या बना) लिया:

1. **अपना प्रॉम्प्ट कॉपी करें** - ऊपर दिए गए टेम्पलेट से या Prompt Builder से
2. **Claude Code खोलें** - एक नई chat शुरू करें
3. **पेस्ट करें और चलाएं** - Claude Code को अपना प्रॉम्प्ट दें और जादू होते देखें!

हम अगले भाग में इसे चरण-दर-चरण देखेंगे।
