इससे पहले कि हम installations और setups में जाएं, आइए अभी **इसी वक्त** देखें कि AI क्या कर सकती है।

ChatGPT, Grok और Claude पश्चिमी दुनिया के लोकप्रिय LLMs हैं। इस अभ्यास के लिए हम Claude का उपयोग करेंगे, हालांकि आप अपनी पसंद के किसी भी LLM से यह आज़मा सकते हैं।

## Claude क्या है?

Claude को एक **बेहद स्मार्ट सहायक** की तरह समझें, जिससे आप एक chat interface के ज़रिए सामान्य भाषा में बात कर सकते हैं। आज आप Claude और अन्य LLMs का उपयोग blog posts संपादित करने से लेकर images बनाने और यहाँ तक कि पूरी तरह से विकसित apps बनाने तक कई तरह के कार्यों के लिए कर सकते हैं।

Claude में **Artifacts** नाम की एक सुविधा है जो आपको अपने browser में तुरंत चीज़ें बनाने देती है — किसी setup की ज़रूरत नहीं!

### चरण 1: Claude खोलें

अपने browser में [claude.ai](https://claude.ai/) पर जाएं और एक account बनाएं।

### चरण 2: Claude से कुछ बनाने को कहें

Login करने के बाद, आपको एक input field वाला interface दिखेगा। खुद को परिचित करने के लिए Claude से कुछ सरल सवाल पूछें।

जब आप तैयार हों, तो चलिए अपना पहला AI-assisted artifact बनाते हैं।

यह prompt Claude में copy और paste करें:

```
Can you create Tetris as a Claude Artifact?
```

**Enter** दबाएं और देखें!

नोट: आप चाहें तो कोई भी अन्य सरल game बनाने के लिए कह सकते हैं, या इन अतिरिक्त [Prompts](#additional-prompts) को देख सकते हैं।

### चरण 3: जादू देखें

कुछ ही सेकंड में, Claude आपके browser में एक **काम करने वाला Tetris game** बना देगा!

![Claude doing it's magic in browser](../../quick-win/tetris.png)

### चरण 4: परिणाम को बेहतर बनाएं

क्या परिणाम आपकी अपेक्षा के अनुसार था?
अगर नहीं, तो उसे बदलाव करने के लिए कहें।

उदाहरण के लिए, आप उससे visual style बदलने या कुछ मज़ेदार नए game elements जोड़ने को कह सकते हैं।

✅ आपने AI के साथ अपना पहला app बना लिया!
सब कुछ 5 मिनट के अंदर। सोचिए, ज़्यादा समय के साथ आप क्या बना सकते हैं।

## अतिरिक्त Prompts

यहाँ कुछ मज़ेदार चीज़ें हैं जो आप Claude से बनाने के लिए कह सकते हैं:

### एक Pomodoro Timer

```
Create a Pomodoro timer with 25-minute work sessions and 5-minute breaks.
Add start, pause, and reset buttons. Show the time in a large, easy-to-read format.
```

### एक Color Palette Generator

```
Create a color palette generator that shows 5 harmonious colors.
Add a "Generate New Palette" button. Show the hex codes for each color and let me click to copy them.
```

### एक सरल Game

```
Create a simple memory card matching game with 8 pairs of cards. When I click two cards, show if they match. Track my number of moves.
```

## यह क्यों मायने रखता है

आपने अभी जो किया वही इस workshop में हम सीखेंगे:

1. **आपने AI को निर्देश दिए** (एक prompt)
2. **AI ने कुछ उपयोगी बनाया** (ऐसा code जो काम करता है)
3. **आपने उसे तुरंत इस्तेमाल किया** (कोई जटिल setup नहीं)

फ़र्क क्या है? **Claude Artifacts** आपके browser में अस्थायी रूप से चलते हैं। इस workshop में, आप सीखेंगे कि कैसे:

- ऐसे projects बनाएं जो internet पर **स्थायी रूप से रहें**
- चीज़ें **अपने खुद के computer पर** बनाएं
- अपने code पर **पूरा नियंत्रण** रखें
- अपनी रचनाएं **दुनिया में किसी के भी साथ** साझा करें

## और अधिक के लिए तैयार हैं?

अब जब आपने देख लिया कि क्या संभव है, तो आइए उन tools को set up करें जो आपको वह सब कुछ बनाने देंगे जो आप सोच सकते हैं।
