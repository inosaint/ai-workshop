अब जब Claude Code ने आपका प्रोजेक्ट बना दिया है और आप इसे अपने सिस्टम पर देख पा रहे हैं, तो आप इसमें बदलाव और सुधार करना चाहेंगे। यहाँ बताया गया है कैसे!

## बदलाव करना

कुछ बदलना चाहते हैं? आपके पास दो विकल्प हैं:

## तरीका 1: Claude Code से पूछें (अनुशंसित)

सबसे आसान तरीका - बस Claude Code को बताएं क्या बदलना है या कुछ स्क्रीनशॉट या डिज़ाइन इमेज शेयर करें (केवल PNG, GIF, WebP, JPEG इमेज समर्थित हैं, कोई PDF नहीं)

```text
Change the heading font to something more playful
```

```text
Make the buttons bigger and add rounded corners
```

```text
Add a footer with copyright information
```

## तरीका 2: फ़ाइलें खुद संपादित करें

आप किसी भी टेक्स्ट एडिटर का उपयोग करके सीधे फ़ाइलें संपादित कर सकते हैं:

1. किसी टेक्स्ट एडिटर में फ़ाइल खोलें (VS Code, Notepad++, TextEdit, आदि)
2. अपने बदलाव करें
3. फ़ाइल सहेजें
4. बदलाव देखने के लिए अपना ब्राउज़र रिफ्रेश करें

<div class="tip-box">
  <strong>💡 प्रो टिप:</strong> खुद छोटे-छोटे बदलाव करके देखें! अगर कुछ टूट जाए, तो आप हमेशा Claude Code से ठीक करने के लिए कह सकते हैं।
</div>

### GitHub Desktop के साथ अपनी प्रगति सहेजें

अपने प्रोजेक्ट में बदलाव करने के बाद, आइए GitHub Desktop के साथ उन्हें सहेजें:

#### चरण 1: GitHub Desktop खोलें

1. GitHub Desktop पर स्विच करें।
2. '**Fetch Origin**' पर क्लिक करें यदि आप Claude Code द्वारा किए गए बदलाव fetch करना और स्थानीय रूप से सत्यापित करना चाहते हैं।
3. यदि आपने एडिटर में मैन्युअल रूप से कोई बदलाव किए हैं, तो आपको "Changes" टैब में अपनी नई फ़ाइलें सूचीबद्ध दिखनी चाहिए।

<div class="tip-box">
  यदि आपने Claude से आपके लिए बदलाव करने के लिए कहा था, तो आप नीचे लिखे चरण 2 और 3 को छोड़ सकते हैं।
</div>

#### चरण 2: अपने बदलाव समीक्षा करें

यह देखने के लिए फ़ाइलों पर क्लिक करें कि क्या बनाया या संशोधित किया गया था। सभी बदली हुई फ़ाइलें चेक होनी चाहिए।

![अपने बदलाव मैन्युअल रूप से चेक करना](../../making-changes/checking-in.png)

#### चरण 3: अपने बदलाव Commit करें

1. नीचे बाईं ओर "Summary" फ़ील्ड में, कुछ ऐसा टाइप करें जो आपके द्वारा किए गए बदलावों का वर्णन करे
   - पहली बार: `Initial project created with Claude Code`
   - बदलावों के बाद: `Updated button styles and added footer`
1. **"Commit to branch"** बटन पर क्लिक करें

## सर्वोत्तम अभ्यास

### 1. अक्सर Commit करें
सार्थक commit संदेशों के साथ अपना काम बार-बार सहेजें। इससे एक इतिहास बनता है जिसे आप बाद में देख सकते हैं।

### 2. Commit करने से पहले परीक्षण करें
यह सुनिश्चित करने के लिए कि बदलाव अपेक्षित रूप से काम कर रहे हैं, commit करने से पहले हमेशा ब्राउज़र में अपने बदलाव देखें।

### 3. स्पष्ट Commit संदेश लिखें
"updates" या "changes" के बजाय, लिखें:
- "Add contact form with validation"
- "Fix navigation menu alignment"
- "Update color scheme to blue"

आप Claude से इन्हें लिखने में मदद माँग सकते हैं।
