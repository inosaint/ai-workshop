## Pilihan 4: Bangun Ide Anda Sendiri!

Punya sesuatu yang lain dalam pikiran? Gunakan Pembuat Prompt kami untuk membuat prompt proyek Anda sendiri!

<div className="prompt-editor">
  <h3>✨ Pembuat Prompt</h3>

  <div className="prompt-fields">
    <div className="prompt-field">
      <label htmlFor="projectType">Jenis proyek apa?</label>
      <select id="projectType">
        <option value="">Pilih jenis...</option>
        <option value="website">Website / Landing Page</option>
        <option value="game">Game</option>
        <option value="tool">Utilitas / Alat</option>
        <option value="dashboard">Dashboard</option>
        <option value="other">Lainnya</option>
      </select>
    </div>

    <div className="prompt-field">
      <label htmlFor="projectIdea">Deskripsikan ide Anda (1-2 kalimat)</label>
      <textarea id="projectIdea" placeholder="mis., Pengatur resep tempat saya bisa menyimpan dan mencari resep favorit saya"></textarea>
    </div>

    <div className="prompt-field">
      <label htmlFor="projectFeatures">Fitur utama (dipisahkan koma)</label>
      <input type="text" id="projectFeatures" placeholder="mis., pencarian, favorit, kategori, mode gelap" />
    </div>

    <div className="prompt-field">
      <label htmlFor="projectColors">Preferensi warna (opsional)</label>
      <input type="text" id="projectColors" placeholder="mis., biru dan putih, tema gelap, warna-warni" />
    </div>
  </div>

  <button id="generateBtn" className="prompt-button">
    Buat Prompt Saya
  </button>

  <div id="generatedPrompt" className="generated-prompt">
    <label>Prompt kustom Anda:</label>
    <div className="prompt-output-wrapper">
      <pre id="promptOutput"></pre>
      <button id="copyBtn" className="copy-button">
        Salin
      </button>
    </div>
  </div>
</div>

<script>
{`
(function() {
  function init() {
    const generateBtn = document.getElementById('generateBtn');
    const copyBtn = document.getElementById('copyBtn');

    if (generateBtn) {
      generateBtn.addEventListener('click', generatePrompt);
    }

    if (copyBtn) {
      copyBtn.addEventListener('click', copyPrompt);
    }
  }

  function generatePrompt() {
    const type = document.getElementById('projectType').value;
    const idea = document.getElementById('projectIdea').value;
    const features = document.getElementById('projectFeatures').value;
    const colors = document.getElementById('projectColors').value;

    if (!idea) {
      alert('Tolong deskripsikan ide proyek Anda!');
      return;
    }

    let prompt = 'Create a ' + (type || 'web project') + ':\\n\\n';
    prompt += 'Main concept: ' + idea + '\\n\\n';
    prompt += 'Features to include:\\n';

    if (features) {
      features.split(',').forEach(feature => {
        prompt += '- ' + feature.trim() + '\\n';
      });
    } else {
      prompt += '- [Add your key features here]\\n';
    }

    prompt += '\\nAdditional requirements:\\n';
    if (colors) {
      prompt += '- Color scheme: ' + colors + '\\n';
    }
    prompt += '- Mobile-responsive design\\n';
    prompt += '- Clean, modern UI\\n';
    prompt += '- Use HTML, CSS, and vanilla JavaScript only\\n';
    prompt += '- Include helpful comments in the code';

    document.getElementById('promptOutput').textContent = prompt;
    document.getElementById('generatedPrompt').classList.add('show');
  }

  function copyPrompt() {
    const prompt = document.getElementById('promptOutput').textContent;
    navigator.clipboard.writeText(prompt).then(() => {
      const btn = document.getElementById('copyBtn');
      btn.textContent = 'Tersalin!';
      btn.style.background = '#10b981';
      setTimeout(() => {
        btn.textContent = 'Salin';
        btn.style.background = 'var(--sl-color-accent)';
      }, 2000);
    });
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', init);
  } else {
    init();
  }
})();
`}
</script>


## Tips Menulis Prompt yang Baik

<div className="tip-box">
  <strong>💡 Tips Menulis Prompt:</strong>
  <ul style={{margin: '0.5rem 0 0 0', paddingLeft: '1.5rem'}}>
    <li><strong>Spesifik</strong> — "Formulir kontak" itu samar; "Formulir kontak dengan kolom nama, email, pesan, dan validasi" itu jelas</li>
    <li><strong>Daftar fitur</strong> — Poin-poin membantu Claude Code memahami tepat apa yang Anda inginkan</li>
    <li><strong>Sebutkan teknologinya</strong> — "Gunakan HTML, CSS, dan JavaScript" menjaga hal-hal tetap sederhana untuk pemula</li>
    <li><strong>Deskripsikan tampilannya</strong> — "Modern dan minimalis" atau "Seru dan berwarna" memandu desain</li>
  </ul>
</div>


## Apa yang Terjadi Selanjutnya?

Setelah Anda memilih (atau membuat) proyek Anda:

1. **Salin prompt Anda** — Baik dari template di atas atau dari Pembuat Prompt
2. **Buka Claude Code** — Mulai chat baru
3. **Tempel dan jalankan** — Berikan Claude Code prompt Anda dan saksikan keajaibannya!

Kita akan membahas ini langkah demi langkah di bagian berikutnya.
