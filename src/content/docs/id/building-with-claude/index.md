Inilah momen yang telah Anda nantikan! Mari gunakan Claude Code untuk membangun proyek Anda.

### Langkah 1: Buka chat Claude Code baru

![Pengaturan Chat Baru](../../building-with-claude/new-project.png)

1. Pilih repository tempat Anda ingin Claude bekerja. Mis., username/username.github.io
2. Pilih lingkungan Cloud default
3. Tempel prompt Anda
4. (opsional) Tambahkan gambar sebagai referensi desain


### Langkah 2: Amati dan Pelajari

Claude Code akan:

1. **Merencanakan** — Memikirkan pendekatan terbaik
2. **Membuat file** — Menghasilkan file HTML, CSS, dan JavaScript
3. **Menjelaskan** — Memberi tahu Anda apa yang dilakukan dan mengapa

![Tampilan percakapan Chat yang sebagian besar satu arah](../../building-with-claude/example-convo.png)

<div class="warning-box">
  <strong>⚠️ Bersabarlah!</strong> Proyek yang kompleks mungkin membutuhkan satu atau dua menit. Jangan ganggu Claude Code saat sedang bekerja.
</div>


### Langkah 3: Tinjau Apa yang Dibuat

![Claude akan mendorong perubahannya ke sebuah branch](../../building-with-claude/claude-branch.png)

Setelah Claude Code selesai, mari lihat file apa yang dibuat. Claude Code akan membuat branch baru dan mendorong pekerjaannya ke branch tersebut. Anda perlu *fetch* perubahan tersebut ke sistem lokal untuk ditinjau.

## Pemecahan Masalah

### Repo Github belum terinstal

![Aplikasi Github belum terinstal](../../building-with-claude/github-connection.png)

Anda perlu menghubungkan kembali Integrasi Github dan memilih repository yang sedang Anda kerjakan.
