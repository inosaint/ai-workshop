# Branch 2 — SEO / AEO / GEO (`claude/seo-aeo-geo`)

Part of the howtoaicode.com investment plan. This branch layers SEO, Answer-Engine, and Generative-Engine optimization on top of the domain fix. Merge order: after `claude/domain-fix` so the new `site` URL is in place when JSON-LD URLs are stamped into the build.

## Why

The site already has solid foundations (Open Graph tags, `Course` and `WebSite` JSON-LD, `llms.txt`). Big wins still on the table for discoverability:
- This is a how-to course — `HowTo` schema unlocks rich snippets in Google search results
- The cheat-sheet and troubleshooting pages are Q&A heavy — `FAQPage` schema makes them eligible for the "People also ask" surface
- `BreadcrumbList` schema helps both Google and AI crawlers understand site structure
- Explicit `robots.txt` opt-in for AI crawlers (GPTBot, PerplexityBot, ClaudeBot, Google-Extended) makes the site eligible to be cited in ChatGPT, Perplexity, and Google's AI Overviews
- `llms-full.txt` (a long-form snapshot variant of `llms.txt`) lets AI crawlers ingest the whole course in one pass

## Changes

- [ ] `public/robots.txt` — point to the auto-generated `/sitemap-index.xml` (Starlight's bundled sitemap integration already emits it; verified in Branch 1's build); explicitly `Allow: /` for `GPTBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`
- [ ] `public/llms-full.txt` — long-form variant with each page's content concatenated under headings; can be generated by a small `scripts/build-llms-full.mjs` that walks `src/content/docs/`
- [ ] Consolidate the existing `src/components/posthog.astro` Head override so it also injects per-page JSON-LD (Starlight permits only one `Head` override):
  - [ ] `HowTo` schema for `setup/*`, `build-your-project/*`, `go-live/*`, and `quick-win/*`
  - [ ] `FAQPage` schema for `troubleshooting/` and `reference/cheat-sheet/`
  - [ ] `BreadcrumbList` for every docs page
- [ ] Frontmatter audit: every page has a `description` of ≤ 160 chars
- [ ] (Reserved) hreflang helper — small util that returns alternate-locale links; consumed by Branch 4 once Chinese ships
